# Time Timer (Desktop)

책상 위에 띄워두고 쓰는 시각적 타이머입니다. Google Time Timer처럼 남은 시간이 빨간 면적으로 줄어드는 방식이라, 시계를 읽지 않아도 얼마나 남았는지 한눈에 들어옵니다.

원래 PyQt5로 만들었는데 더 가볍고 손보기 쉬운 UI가 필요해서 Tauri(React + TypeScript)로 다시 썼습니다. 예전 파이썬 버전은 `legacy/` 폴더에 그대로 남겨뒀습니다.

## 어떻게 쓰나

다이얼을 클릭하거나 드래그하면 시간이 잡힙니다 (12시가 0, 시계방향, 1분 단위). 시작하면 빨간 면적이 부드럽게 줄어들고, 끝나면 소리나 알림으로 알려줍니다. 창은 테두리 없이 떠 있고 크기를 바꿔도 다이얼은 늘 동그란 비율을 유지합니다.

작업하면서 옆에 켜두는 용도라 방해가 되지 않도록 몇 가지를 신경 썼습니다.

- **미니 모드** — 창을 작게(200×250 이하) 줄이면 부가 요소가 사라지고 도넛 모양 다이얼만 남습니다. 이 상태에선 다이얼을 클릭해 시작/정지하고, 링을 드래그해 시간을 맞춥니다.
- **가림 방지** — 타이머가 뒤 작업을 가리지 않게 세 가지 중에서 고를 수 있습니다. 투명도를 수동으로 낮추거나, 커서를 올리면 반투명해지게 하거나, 아예 커서가 올라오면 클릭이 뒤로 통과되게 할 수도 있습니다.
- **항상 위 고정** — 📌 버튼으로 켜고 끕니다.

끝났을 때 알림은 소리, 화면 깜빡임(무음 모드), OS 알림 배너를 골라서 조합하면 됩니다. 내장 알림음은 7종인데 실행 중에 파형을 합성해 만들기 때문에 별도 음원 파일이 없습니다.

집중용으로 뽀모도로도 넣었습니다. 25/5분 같은 고정 규칙 대신 구간을 직접 짜는 방식이라, 각 구간의 이름·길이·색을 정해서 순서대로 돌립니다. 자동으로 다음 구간으로 넘어가게 하거나 전체를 반복시킬 수 있습니다.

굳이 창을 띄워두지 않아도 되도록 시스템 트레이에 상주하고, 전역 단축키로 조작할 수 있습니다.

| 단축키 | 동작 |
| --- | --- |
| `Ctrl+Shift+Space` | 시작 / 정지 |
| `Ctrl+Shift+R` | 리셋 |
| `Ctrl+Shift+T` | 창 표시 / 숨김 |
| `Ctrl+Shift+O` | 가림 방지 모드 전환 |

창을 닫아도 완전히 꺼지지 않고 트레이로 들어갑니다. 종료는 트레이 아이콘 우클릭 메뉴에서 하면 됩니다. 설정값과 창 위치·크기는 자동으로 저장돼서 다시 켜면 그대로 복원됩니다.

## 실행

Node.js와 Rust 툴체인이 있어야 합니다. Windows라면 Rust를 설치할 때 MSVC 빌드 도구도 같이 깔려 있어야 링크가 됩니다.

```bash
npm install
npm run tauri dev
```

## 빌드

```bash
npm run tauri build
```

설치 파일(.msi / .exe)은 `src-tauri/target/release/bundle/` 아래에 생깁니다. 처음 빌드할 때는 Rust 의존성을 전부 컴파일하느라 몇 분 걸립니다.

## 구조

```
src/          React 프론트엔드 — 다이얼, 설정, 뽀모도로, 훅, 사운드 합성
src-tauri/    Rust 백엔드 — 창 제어, 트레이, 전역 커서 폴링, 플러그인
legacy/       예전 PyQt5 버전
DESIGN.md     재작성 당시 남긴 설계 메모
```

색이나 다이얼 생김새는 대부분 `src/App.css`와 `src/components/*.css`의 CSS 변수로 조정할 수 있고, 라이트/다크 테마는 시스템 설정을 따라갑니다.
